# Sources

Links and notes on where the research claims in the README came from.

### Icon clarity

**9to5Google — YouTube Music getting more obvious shuffle and repeat buttons**
https://9to5google.com/2025/07/11/youtube-music-shuffle-repeat/
Confirms the icon ambiguity is real and that YouTube added a white dot under the icon to make the repeat-all state clearer. The repeat-one state wasn't touched in this update.

**PUSH.fm — Visual updates to YouTube Music's shuffle and repeat buttons**
https://blog.push.fm/21430/updates-youtube-musics-shuffle-repeat/
Same update, frames it as a direct response to user complaints about not being able to tell if shuffle/repeat were on.

**TechWiser — What Do Symbols and Icons Mean on YouTube Music**
https://techwiser.com/what-do-symbols-and-icons-mean-on-youtube-music/
Just a plain explainer of what each tap of the repeat button currently does — useful as a baseline for how many taps it takes to even get an explanation.

### Repeat-once vs repeat-forever confusion

**Spotify Community — The repeat-one/loop button**
https://community.spotify.com/t5/Spotify-for-Developers/The-repeat-one-loop-button/td-p/5502794
A user describes the exact confusion I ran into — says the icon feels like it's showing the opposite of what it actually does.

**Deezer Community — is there an option for an individual song to play indefinitely / repeat forever?**
https://en.deezercommunity.com/android-47/is-there-an-option-for-an-individual-song-to-play-indefinitely-repeat-forever-73470
A user asking whether a song can loop forever, since the app only seems to let them repeat it once before it moves on — this is basically asking for the exact distinction I'm proposing (once vs. infinite).

**Spotify Community — Repeat TRACK Mode!**
https://community.spotify.com/t5/Implemented-Ideas/Repeat-TRACK-Mode/idc-p/1367
An old thread (years old) where users campaigned for a dedicated single-track repeat mode before Spotify added one. Good evidence that this category of feature has real, demonstrated demand once it actually ships.

### Duplicate / confusing track titles

**Spotify Community — Remove duplicates**
https://community.spotify.com/t5/Live-Ideas/Remove-duplicates/idc-p/5993706/highlight/true
Multiple users saying the same song shows up 2-3 times under different metadata/versions, calling it confusing and asking for better deduplication.

**Spotify Community — Saved songs do not show up on Artist pages**
https://community.spotify.com/t5/Desktop-Windows/Saved-songs-do-not-show-up-on-Artist-pages/m-p/4528539/highlight/true
A user specifically asking why there are "so many versions" of the same album or song, even when there's no deluxe or special edition involved.

**Spotify Community — Duplicates (iOS thread)**
https://community.spotify.com:443/t5/iOS-iPhone-iPad/Duplicates/td-p/5575357
Spotify's own support response in this thread confirms that different metadata for the same underlying track (e.g. deluxe vs standard) is a known, still-unresolved source of duplicate-looking entries.
